# kata

A training ground for deep C++ and systems interviews.

**https://kata-black.vercel.app**

- **Questions.** Read a snippet or scenario and predict what actually
  happens, the way a compiler or kernel would. Covers C++, Rust, operating
  systems, concurrency, networking, computer architecture, compilers,
  GPU/CUDA, design patterns, and data structures & algorithms.
- **Coding.** Write real solutions and run them against test cases.
- **Progress.** Track accuracy and streaks per category, and get pointed at
  your weakest area and the questions you missed. Sign in to keep progress
  across devices.

Found a wrong answer or a confusing question? Open an issue.
